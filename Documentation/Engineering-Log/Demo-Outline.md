# Product walkthrough recordings

The recorded walkthroughs are linked in the [README](../../README.md#watch-angrove-in-use):
a 1:49 conversation and Insight Tree demo, a 0:24 saved-ideas demo, and a 0:50 read-aloud demo,
captured October 8, 2026. The [October 22 media set](../Screenshots/2026-10-22/README.md)
also includes Mac Boards recordings.

The original outline below records the intended narrative for a 90–120 second walkthrough:

| Time | Show | Explain |
| --- | --- | --- |
| 0–15 s | Home, then a question | The user problem: staying with a serious question in a private workspace |
| 15–45 s | A completed answer and its source | Local inference and inspectable primary-source evidence; disclose a cut or time-lapse across generation |
| 45–65 s | Tap a term, read its contextual definition, save it | The user decides which concepts become durable Insights |
| 65–90 s | Insight Tree and Study view | Semantic relatedness organizes the saved concepts; distance does not establish truth |
| 90–110 s | Model Tasks or offline demonstration | The system around the model: local work, visible scheduling, explicit failure behavior |
| 110–120 s | Return to the question | What you built and the next validation step |

Use a question whose answer and citations you have checked against the bundled Library. Avoid
presenting the website's editorial examples as live model output. Show the build, device and
capture date in the description. If demonstrating encryption, explain saved-data coverage rather
than suggesting an unlocked screen or exported JSON is encrypted.
